# VYUH IKE

**IPsec negotiation and protected traffic corpus** · v0.1.0 · MIT

Eleven packet captures of real IPsec tunnels, produced by two strongSwan 5.9.13
gateways that actually negotiated with each other. 4,290 packets, 3,530 of them
ESP, across IKEv1 and IKEv2.

## Three things to know before you use it

1. **The traffic classes are synthetic.** They are deliberately shaped packet
   patterns — an interactive cadence, a bulk cadence, a 20 ms voice cadence, a
   10 ms streaming cadence — not sessions captured from WhatsApp, a mail client
   or a video call. A model fitted on them learns the generator, not the
   network.

2. **T3 has no data plane.** The IKEv1 association never settled, so that
   capture is a handshake and nothing else. Its findings are real and its score
   of 0 is correct: a tunnel that does not come up is not a passing tunnel.

3. **Four IKEv1 captures carry no ESP data.** strongSwan establishes the IKE SA
   and the child does not settle in this environment, so those rows show zero
   ESP packets. The handshakes parse fully and their findings are correct; only
   the data plane is missing.

4. **The analyser scores the IKE suite, not the ESP suite.** Two further
   captures that would expose this are built and deliberately withheld from this
   release. They land in 0.2.0, and `DATASET-CARD.md` says which and why.

5. **PFS is never observed.** No capture contains a rekey, so perfect forward
   secrecy can be neither confirmed nor denied from the wire. This is the
   largest gap in the release.

The remaining limits — IPv4 only, tunnel mode only, one vendor — are in the
dataset card. This dataset is released incrementally; the version history and
what 0.2.0 will add are in the card too.

## Provenance

```
python3 scripts/make-corpus.py     # regenerate all six captures
python3 scripts/build-dataset.py    # rebuild the tables
cargo test --workspace              # check the dissector against tcpdump
```

Every label in this dataset was set before the packet was sent, and the
generator's log of when each class ran ships beside the capture. That is the
property worth having: a reviewer can disagree with the analysis and still know
what the ground truth was.
