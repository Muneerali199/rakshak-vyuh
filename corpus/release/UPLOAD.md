# VYUH IKE — upload instructions

Everything you need to type into the AIKosh dataset submission form, with the
value to use in each field. The archive to upload is `vyuh-ike-v0.1.0.zip`.

There is no programmatic upload path. The AIKosh Python SDK (v2.0.0) exposes
`list_datasets`, `get_dataset_metadata`, `list_files` and `download` — the
dataset endpoint is `sdk-dataset/list`, and no create or upload call exists in
the SDK. The submission goes through the web portal, once, by hand.

---

## 1. Title

```
VYUH IKE: IPsec negotiation and protected traffic corpus
```

## 2. Description

```
Six packet captures of real IPsec tunnels, produced by two strongSwan 5.9.13
gateways that actually negotiated with each other. Each capture is paired with
the security suite that went onto the wire, the findings derived from it, and
the SHA-256 of the capture file.

Every traffic label was set before the packet was sent, by the component that
generated it, and the generator's own class log ships beside each capture so a
reviewer can check the label against the record of when that class was sent.
Nothing was inferred from traffic after the fact.

The tunnels span IKEv1 and IKEv2, and between them they cover the failure modes
that matter in practice: a 1024-bit MODP group, NULL encryption, 3DES, SHA-1
integrity, and an IKEv1 Aggressive Mode association whose identity payload is
unauthenticated. The corpus is small and the traffic classes are synthetic
packet patterns rather than real application sessions; both limits are stated
in the dataset card, which ships inside the archive.
```

## 3. Sector

Cybersecurity. If the form has a narrower option, take the closest one to
network security. Confirm the exact `sector_id` from the SDK once the key is
available:

```python
import aikosh, json
aikosh.set_api_key(KEY)
print(json.dumps(aikosh.get_datasets_filter_info(), indent=2))
```

The response carries `organisationList`, `sectorsList`, `licensesList` and
`datasetTypesList`, each with an `id` and a `name`. Use those `id` values
verbatim rather than guessing; a wrong id is a silent no-op on the form.

## 4. Licence

MIT. The text is at `corpus/LICENSE` and inside the archive. The captures were
generated by MIT-licensed software on isolated Docker networks and contain no
traffic from any real network or any real user, so there is no privacy basis
requiring a more restrictive licence.

## 5. Dataset type

Network capture / packet trace. If `datasetTypesList` offers something like
"Network Data" or "Pcap", use it; otherwise the closest structured-data option.

## 6. Language

English.

## 9. Access scope

Open. Everything in the archive is already public and carries no personal data.

## 10. Contributor declaration

State plainly that the corpus is synthetic-lab-generated and contains no real
network capture. That is the question a reviewer will ask first, and answering
it up front is the difference between a submission that gets vetted and one
that gets held.

## Before you submit, check these

- [ ] `unzip -t vyuh-ike-v0.1.0.zip` — the archive opens cleanly
- [ ] Open one `.pcap` in Wireshark. You should see UDP 500 IKE and UDP 4500
      ESP between the two gateway addresses.
- [ ] Read `DATASET-CARD.md` once. The limits section is what makes the rest of
      the submission credible; do not let a reviewer discover them first.
- [ ] Confirm the title and description contain no claim you cannot point at a
      file for.

## If a reviewer asks "is this really IPsec?"

Point at `tables/capture.csv`: the `encryption`, `key_exchange` and
`grade` columns were read off the wire by an independent dissector, and the
expectations in `crates/vyuh-core/tests/corpus.rs` were taken from
`tcpdump -nvv` and `swanctl --list-sas` on the live gateway, not from the tool
being tested.

## If a reviewer asks "how big is this, really?"

2,986 packets across six tunnels. Small. Say so. It is a seed corpus for
testing a dissector and validating posture rules, and the value is that every
label is verifiable — not the volume.
